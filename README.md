# Трекер задач

Приложение для управления задачами: проекты, статусы, приоритеты, сроки, поиск и фильтры.
Фронтенд написан на React, данные пока хранятся в `localStorage`. Следующий этап: Node.js + Express + PostgreSQL.

## Возможности

- Проекты: создание и удаление (вместе с задачами)
- Задачи: создание, редактирование, удаление, быстрая смена статуса
- Статусы (к выполнению, в работе, готово), приоритеты и сроки с отметкой «просрочено»
- Поиск по названию и описанию, фильтры по статусу и приоритету, сортировка
- Светлая и тёмная тема (по настройкам системы), адаптивная вёрстка
- Доступность: подписи полей, фокус с клавиатуры, нативный `<dialog>`

## Стек

React 18, Vite, Vitest, GitHub Actions (тесты и сборка на каждый push).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # юнит-тесты
npm run build    # production-сборка в dist/
```

## Структура

```
src/
  api/          слой данных (сейчас localStorage, потом fetch к REST API)
  hooks/        useTracker: загрузка и изменение данных
  components/   Sidebar, Toolbar, TaskList, TaskItem, TaskForm
  utils/        чистые функции: фильтрация, сортировка, даты (+ тесты)
```

Логика отделена от интерфейса: фильтры и сортировка лежат в `utils/tasks.js` и покрыты тестами,
а все обращения к данным проходят через `src/api`. Поэтому переход на бэкенд не затронет компоненты.
